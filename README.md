# BirthdayParadoxExperimenter_App
BirthdayParadoxExperimenter: An app to experiment the Birthday Paradox.

## BirthdayParadoxExperimenter: Birthday Paradox Experimenting App: [Link](https://menashasenanayaka.shinyapps.io/birthdayparadoxexperimenter_app/)

The app is designed to experiment with the Birthday Paradox in a simple and user-friendly manner. Users can explore the probability of at least two people sharing the same birthday by changing the group size and conducting simulations.

Note:

* First, select the number of people in the group.
* Specify the number of simulations to be conducted.
* Set a random seed if required.
* Run the experiment and observe the theoretical and simulated probabilities of shared birthdays.
* View the results and explore the birthday probability curve.
* Change the input values and repeat the experiment to explore different scenarios.
* Users can input their own birthday and experiment the paradox.

Limitations:

* The app assumes that birthdays are uniformly distributed across 365 days.
* Leap years are not considered.
* The analysis focuses on the probability of at least two people sharing the same birthday.

This Shiny app will be helpful to anyone curious about the Birthday Paradox. Anyone interested in exploring this probability phenomenon through an interactive tool can take advantage of this app. Even users with no prior experience in statistical software can easily use this application.
